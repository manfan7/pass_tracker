# 🎫 Проездные — учёт сроков

Приложение для отслеживания срока действия проездных билетов: **автобус**, **комбо**, **турист**.

Работает как обычный сайт и как **PWA** — ставится на телефон как приложение и работает офлайн.

**Онлайн-версия:** https://manfan7.github.io/pass_tracker/ — откройте ссылку на телефоне и установите приложение (подробности в «[Как установить на телефон.md](Как%20установить%20на%20телефон.md)»).

## Что умеет

- Добавлять проездной: тип (автобус / комбо / турист), своё имя, длительность **от 1 до 30 суток**, дата покупки.
- Показывать статус: **активен** (сколько дней осталось), **последний день**, **не начался**, **просрочен** (сколько дней назад).
- **Уведомления**: за 1 день до окончания срока приходит напоминание, в нём назван проездной (если заканчивается несколько — перечислены все). На Android напоминание приходит в 9:00, даже если приложение закрыто; на iPhone — при открытии приложения (iOS не разрешает PWA планировать уведомления).
- Календарь: на каждом месяце точками показано, какие проездные действуют, а **обведённая точка** — день окончания. Клик по дню — детали.
- Список с вкладками: «Действующие», «Будущие», «Просроченные». Редактирование и удаление.
- Данные хранятся в самом браузере/телефоне (localStorage) — ничего никуда не отправляется.

## Как считается срок — именно 30 суток, не месяц

Проездной действует **ровно N суток**, начиная с даты покупки. Последний день = дата покупки + N − 1.

Примеры:

| Покупка | Длительность | Действует по |
|---|---|---|
| 5 ноября 2026 | 30 суток | **4 декабря 2026** (не «месяц вперёд») |
| 20 января 2027 | 30 суток | **18 февраля 2027** (январь 31 день — сдвиг влево) |
| 1 марта | 30 суток | 30 марта (февраль бы не учитывался) |

В форме показывается живой предпросмотр «Действует с … по …», так что видно до нажатия кнопки.

## Запуск на компьютере

Нужен установленный [Node.js](https://nodejs.org). В папке проекта:

```bash
npm install        # один раз
npm run build      # сборка
npm run preview -- --host   # открыть на http://localhost:4173
```

Или просто двойной клик по **Запустить.bat** — он сам соберёт и запустит, а для телефона даст адрес вида `http://192.168.x.x:4173`.

Режим разработки (автообновление при правках кода): `npm run dev`.

## Установка на телефон

См. файл **«Как установить на телефон.md»** — там по шагам для Android и iPhone.

## Структура

```
pass-tracker/
├── index.html
├── vite.config.js          # React + PWA (манифест, service worker); base задаётся VITE_PUBLIC_BASE
├── .github/workflows/deploy.yml  # автодеплой на GitHub Pages при push в main
├── scripts/make-icons.mjs  # генерация иконок (npm run icons)
├── public/
│   └── sw-extra.js         # обработчик клика по уведомлению (для service worker)
├── src/
│   ├── App.jsx             # состояние, хранение
│   ├── passes.js           # типы, статусы, localStorage
│   ├── dateUtils.js        # даты: ровно N суток, без часовых поясов
│   ├── notifications.js    # напоминания за 1 день до окончания
│   ├── components/
│   │   ├── PassForm.jsx    # форма добавления/редактирования
│   │   ├── PassList.jsx    # список с вкладками
│   │   ├── Calendar.jsx    # календарь и детали дня
│   │   └── NotificationSettings.jsx  # карточка включения уведомлений
│   └── styles.css
└── dist/                   # готовая сборка (после npm run build)
```

## Публикация

При push в `main` приложение автоматически собирается и публикуется на GitHub Pages
(workflow `.github/workflows/deploy.yml`). Собирается с `VITE_PUBLIC_BASE=/pass_tracker/`,
чтобы все пути работали из подкаталога Pages.

`dist/` — статика: её можно перетащить в [Netlify Drop](https://app.netlify.com/drop), залить на Vercel и любой хостинг. HTTPS-ссылка нужна для полноценной установки на телефон.
